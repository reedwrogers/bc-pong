bc‑pong

A Pong AI trained through behavioral cloning, then fine-tuned with self‑play reinforcement learning

🡡/🡣 arrow keys — first to 5 wins

How It Works

  • Step 1 — Data Collection: Two humans played games against each other; every frame (positions, velocities) was logged to CSV.
  • Step 2 — Behavioral Cloning (BC): A neural network was trained to predict the human paddle action (up/stay/down) from the frame state — a simple supervised classification problem.
  • Step 3 — Reinforcement Learning (RL): The BC model was then fine-tuned via self‑play REINFORCE (vanilla policy gradient) with 64 parallel games, learning to win rather than just mimic.

The Model

MLP 10 → 96 → 96 → 3 ReLU + Dropout 10,659 params

The net sees 10 normalized features each frame: ball position & velocity, both paddle positions, and relative distance vectors from each paddle to the ball. It outputs 3 logits (up / stay / down) and plays argmax-greedy.

Because the model is so small, the entire forward pass runs in vanilla JavaScript in your browser — no backend needed.

Training Stats

BC trained on ~100k frames across 10 recorded games. RL then ran 5,000 self‑play games with REINFORCE (γ=0.95, temperature annealing 1.0→0.05, 64 parallel envs) to push the model beyond imitation into true gameplay strategy.
